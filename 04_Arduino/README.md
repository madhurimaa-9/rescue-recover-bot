# 04 Arduino

This section will contain the Arduino UNO firmware for the physical rover.

## Planned Development Order

1. Arduino and L298N motor control
2. Individual motor testing
3. HC-SR04 obstacle sensing
4. PIR motion sensing
5. MLX90614 temperature sensing
6. GPS integration
7. Sensor integration
8. Communication with the monitoring system

Each subsystem should be tested independently before combining it with the rest of the rover.

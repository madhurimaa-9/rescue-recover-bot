# 05 Testing

Testing will be documented here as the rover moves from simulation to physical hardware.

## Planned Test Categories

- Motor direction and speed
- Obstacle detection distance
- Obstacle avoidance response
- Temperature readings
- Motion detection
- GPS position accuracy
- Camera streaming
- Wireless telemetry
- Battery runtime
- Autonomous search coverage
- Possible survivor detection
- Full mission test

For each test, record the setup, expected result, observed result, and any changes made.
